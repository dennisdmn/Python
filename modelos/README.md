# Modelos

Area para modelos reutilizaveis em projetos Python operacionais.

## Modelos incluidos

- `validar_arquivo_por_colunas_obrigatorias.py`: valida se um DataFrame contem colunas obrigatorias.
- `exportador_excel_sem_mesclas.py`: exporta abas em Excel com formatacao simples, sem celulas mescladas.
- `ordenar_abas_excel_openpyxl.py`: ordena abas de um workbook Excel.
- `pipeline_conciliacao_pandas.py`: modelo generico de conciliacao com pandas.

## Uso por IA

Assistentes como ChatGPT, Claude e Codex devem usar estes arquivos como blocos reutilizaveis, evitando copiar regras de negocio especificas quando o objetivo for criar uma rotina generica.
