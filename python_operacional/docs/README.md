# Documentacao dos arquivos de python_operacional

Esta pasta documenta cada arquivo do pacote `python_operacional/`.

## Objetivo

Permitir que pessoas e assistentes de IA entendam rapidamente:

- para que serve cada modulo;
- quando usar;
- quais funcoes principais existem;
- quais cuidados aplicar;
- como reutilizar em novos scripts operacionais.

## Indice

- `selecao_arquivos.md`
- `inventario_pastas.md`
- `validacao_layouts.md`
- `colunas.md`
- `leitura_excel_pandas.md`
- `leitura_excel_polars.md`
- `sqlite_cache.md`
- `exportacao_excel.md`
- `conciliacao.md`
- `periodos.md`
- `catalogo.md`
- `init.md`
- `requirements.md`

## Regra de uso

Antes de criar novo codigo operacional, consulte primeiro o arquivo de documentacao do modulo correspondente.
