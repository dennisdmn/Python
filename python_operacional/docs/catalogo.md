# catalogo.md

## Objetivo

Servir como mapa rapido entre uma necessidade operacional e o modulo/função correspondente em `python_operacional/`.

## Quando usar

Use no inicio de qualquer novo desenvolvimento para verificar se ja existe bloco reutilizavel.

## Conteudo esperado

O catalogo deve indicar:

- necessidade operacional;
- modulo onde a funcao esta localizada;
- funcao sugerida.

## Cuidados

- Manter o catalogo atualizado quando novos modulos forem criados.
- Evitar listar funcoes experimentais sem documentacao.
- Usar nomes claros e estaveis.

## Orientacao para IA

A IA deve consultar este arquivo antes de criar uma nova funcao. Se a necessidade ja estiver mapeada, deve reutilizar o modulo existente.
