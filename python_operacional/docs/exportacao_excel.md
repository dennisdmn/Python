# exportacao_excel.py

## Objetivo

Padronizar a criacao de arquivos Excel de saida em scripts operacionais.

## Funcoes principais

- `exportar_excel_seguro`
- `ordenar_abas`

## Quando usar

Use quando o script precisar gerar um arquivo Excel final com uma ou mais abas.

## Cuidados

- Manter a formatacao simples.
- Evitar celulas mescladas.
- Separar calculo e formatacao.
- Preservar a ordem das abas quando ela estiver documentada.

## Orientacao para IA

Antes de criar uma nova rotina de exportacao, consultar este modulo e reaproveitar as funcoes existentes.
